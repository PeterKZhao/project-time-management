目标：客户可以从首页进入，提交一个完整的债务健康检查申请，并看到 Mock 初筛结果。

### 首页 / 登录页

- [ ] 首页 CTA 按钮跳转到“开始检查”流程

- [ ] 登录后显示“我的项目”和“开始新检查”入口

### 准入条件页

- [ ] 展示 5 个硬性准入条件
- [ ] 每个条件补充“为什么需要”说明
- [ ] 底部增加“我符合条件，开始检查”按钮

### 多步骤申请表

- [ ] 第一步：企业信息
  - [ ] 企业名称
  - [ ] 统一社会信用代码
  - [ ] 企业类型
  - [ ] 民营股权比例
  - [ ] 联系人
  - [ ] 联系电话
  - [ ] 联系人身份
- [ ] 第二步：债务信息
  - [ ] 欠款方名称
  - [ ] 欠款方类型
  - [ ] 欠款金额
  - [ ] 欠款类型
  - [ ] 逾期时间
  - [ ] 验收 / 审计 / 判决 / 对账状态
  - [ ] 是否部分回款
- [ ] 第三步：五项准入问卷
  - [ ] 企业是否正常存续
  - [ ] 是否实控人/董事长确认
  - [ ] 是否接受 25%～30% 回款后服务费
  - [ ] 是否有基础证据材料
  - [ ] 是否接受较强推进方式
- [ ] 第四步：材料上传 Mock
  - [ ] 合同 / 补充协议
  - [ ] 验收资料 / 完工证明
  - [ ] 审计报告 / 结算书
  - [ ] 对账单 / 确认函
  - [ ] 发票
  - [ ] 付款记录
  - [ ] 催款函 / 沟通记录
  - [ ] 判决书 / 调解书 / 仲裁文书
  - [ ] 其他补充材料

### AI 初筛结果 Mock

- [ ] 展示项目初筛结论：建议受理 / 谨慎受理 / 暂不受理 / 需补充材料
- [ ] 展示债务健康评分 0～100
- [ ] 展示证据完整度、回款可行性、推进难度、决策人确认程度
- [ ] 展示推荐路径、预计周期、建议服务费区间
- [ ] 展示是否需要法务/催收介入
- [ ] 展示缺失材料清单
