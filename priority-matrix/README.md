# 重要紧急四象限

> 用于每周判断先做什么。副业和本职工作仍然分开看：副业决定时间投入，本职工作只决定跟进顺序。

## 判断标准

| 象限 | 含义 | 处理方式 |
|---|---|---|
| Q1 重要且紧急 | 近期可能影响收入、上线、合同、关键交付 | 本周优先处理 |
| Q2 重要不紧急 | 长期价值高，但没有立即截止点 | 持续推进，避免拖成 Q1 |
| Q3 紧急不重要 | 需要跟进或响应，但不是主线价值 | 快速处理/委托/只留下一步 |
| Q4 不重要不紧急 | 暂无明确收入、交付或战略窗口 | 暂缓，只保留观察 |

1. Q1 同象限先看主业：`AML Agentic AI`、`Revise Benefit Amount`、`FE Skill Building`、`ADF`、`SnapOne AI`；副业看 `高考志愿填报`、`蓝鹦鹉在线教育`、`支付编排 / MCN/KOL ERPNext 架构`。

4. 副业等待：`新粮` 只跟签约，不提前重投入；`AI 中转站做视频生成` 先整理产品入口、调用链路和演示场景。
