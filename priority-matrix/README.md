# 重要紧急四象限

> 用于每周判断先做什么。副业和本职工作仍然分开看：副业决定时间投入，本职工作只决定跟进顺序。

> 2026-08-05 已校正 Enterprise Service：它属于副业，不属于本职工作。副业 AI 软件工厂 / youlidao.ai 与正式工作的主业 AI 平台分开管理。

## 判断标准

| 象限 | 含义 | 处理方式 |
|---|---|---|
| Q1 重要且紧急 | 近期可能影响收入、上线、合同、关键交付 | 本周优先处理 |
| Q2 重要不紧急 | 长期价值高，但没有立即截止点 | 持续推进，避免拖成 Q1 |
| Q3 紧急不重要 | 需要跟进或响应，但不是主线价值 | 快速处理/委托/只留下一步 |
| Q4 不重要不紧急 | 暂无明确收入、交付或战略窗口 | 暂缓，只保留观察 |
