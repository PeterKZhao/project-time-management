## 使用原则

1. 副业项目用于每周时间分配和优先级排序。
2. 本职工作只记录跟进点、阻塞和下一步，不参与副业排序。
3. 能力中心/平台型 BU 可以进入同一 dashboard，但不和具体业务的 Q1 优先级混算。
4. 重要紧急四象限用于每周判断先处理哪些项目。
5. 每周复盘时先看副业主攻项目，再单独看本职工作跟进项。

## 信息治理

1. GitHub Organization 是资产归属的真相源。
2. 各 Organization 的 `requirements` 仓库是业务需求的真相源。
3. 本仓库文档是项目优先级的真相源。
4. GitHub Issues 是当前可执行任务的真相源。
