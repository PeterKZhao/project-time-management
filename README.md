  - [Enterprise Service 副业项目跟进](side-business/enterprise-service.md)

## 使用原则

1. 副业项目用于每周时间分配和优先级排序。
2. 本职工作只记录跟进点、阻塞和下一步，不参与副业排序。
3. `Enterprise Service` 是副业中的对外客户技术赋能业务，不属于 `official-work`。
4. `AI 软件工厂 / youlidao.ai` 属于副业；正式工作的主业 AI 平台只在 `official-work` 中跟进，两者不混用。
5. 能力中心/平台型 BU 可以进入同一 dashboard，但不和具体业务的 Q1 优先级混算。
6. 重要紧急四象限用于每周判断先处理哪些项目；每周先选副业主攻项，再单独看主业跟进项。

## 信息治理

1. GitHub Organization 是资产归属的真相源。
2. 各 Organization 的 `requirements` 仓库是业务需求的真相源。
3. 本仓库文档是项目优先级的真相源。
4. GitHub Issues 是当前可执行任务的真相源。
